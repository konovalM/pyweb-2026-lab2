# pyweb2025 — Задание 2. Развёртывание автономного агента для научных задач

Репозиторий с материалами и артефактами ко **второму заданию** курса
«Проектирование и развёртывание веб-решений в эко-системе Python».

Задание: развернуть автономного ИИ-агента (**Hermes Agent**, Nous Research) на
собственном VPS, подключить LLM и Telegram-шлюз, настроить файловую память,
навыки и планировщик, и провести исследование применимости такого агента к
работе веб-инженера-исследователя.

Связано с [Заданием 1](../pyweb2026) — научным сайтом *Predictive Sensorics*
(прогноз остаточного ресурса подшипника по вибродиагностике), публикуемым через
GitHub Pages. Агент из задания P3 обслуживает конвейер публикации этого сайта.

## Структура репозитория

```
pyweb2025-zadanie2/
├── REPORT.md                 # ← главный отчёт (T1–T5, P1–P5, выводы)
├── runbook.md                # пошаговый запуск на VPS (раздел «Ход работы»)
├── deploy/
│   ├── compose.yaml          # docker compose агента (с комментариями)
│   ├── .env.example          # шаблон секретов (ключи вне репозитория!)
│   └── config.yaml           # конфиг модели (OpenRouter free)
├── hermes/                   # содержимое ~/.hermes на сервере
│   ├── memories/
│   │   ├── USER.md           # профиль пользователя (T2)
│   │   └── MEMORY.md         # контекст исследовательской задачи (T2)
│   ├── skills/
│   │   └── arxiv-digest/
│   │       └── SKILL.md      # собственный навык (P2)
│   └── cron/
│       └── arxiv-digest.yaml # расписание навыка
├── experiments/
│   ├── tasks.md              # 10 контрольных задач (P4)
│   └── run-protocol-template.md  # шаблон протокола прогона (T4)
└── screenshots/              # снимки диалогов и логов для отчёта
```

## Безопасность

Агент имеет доступ к терминалу сервера — **доступ к боту равнозначен доступу к
серверу**. Все ключи и токены хранятся только в `~/.hermes/.env` на сервере и
**никогда** не коммитятся (см. `.gitignore`). Модель угроз — раздел T3 отчёта.
