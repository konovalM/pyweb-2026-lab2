# Протокол прогона агента — шаблон (T4)

Заполняется для КАЖДОГО прогона эксперимента P4 (и для любого прогона, результат
которого идёт в отчёт). Цель — чтобы прогон можно было описать и воспроизвести.

## Паспорт прогона
| Поле | Значение |
|------|----------|
| ID прогона | `P4-T{задача}-M{модель}-r{повтор}` напр. `P4-T01-M1-r2` |
| Дата/время (UTC) | 2026-11-__ __:__ |
| Задача (из tasks.md) | #__ — … |
| Критерий успеха | … |
| **Модель** (точный id) | `meta-llama/llama-3.3-70b-instruct:free` |
| Версия/снапшот модели | как отдаёт провайдер (если доступно) |
| Провайдер | OpenRouter |
| Температура / сэмплинг | 0.2 / top_p 1.0 |
| Системный промпт (хэш/версия) | `sha256:…` или «default v1» |
| Состав навыков на момент старта | напр. [arxiv-digest] |
| Память на момент старта (хэш) | USER.md `sha256:…`, MEMORY.md `sha256:…` |

## След выполнения
| Поле | Значение |
|------|----------|
| Вызванные инструменты (по шагам) | web_fetch → files → … |
| Число шагов | __ |
| Время, с | __ |
| Токены вход / выход | __ / __ |
| Стоимость, $ (или 0 для free) | __ |
| Полный лог шагов | ссылка на файл `logs/P4-…md` |

## Результат
| Поле | Значение |
|------|----------|
| Успех по критерию (0/1) | __ |
| Непроверяемые/ложные утверждения | да/нет — какие |
| Выдуманные ссылки | да/нет |
| Тип отказа (если был) | зацикливание / преждевр. остановка / выдуманная ссылка / неверный вызов инструмента |
| Комментарий проверяющего (человека) | … |

---
> Хэши памяти/промпта: `sha256sum ~/.hermes/memories/*.md`.
> Что зафиксировать нельзя: точный снапшот модели на стороне провайдера и
> изменяющееся содержимое веб-источников — отметить это в ограничениях (T4).
