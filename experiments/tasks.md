# P4 — Набор контрольных задач

12 задач, отражающих реальную работу веб-инженера-исследователя. У каждой —
критерий успеха, **проверяемый независимо от агента** (человеком или скриптом).
Эксперимент: ≥2 модели × 3 прогона каждой задачи (см. `run-protocol-template.md`).

| #  | Класс | Задача | Критерий успеха (независимый) |
|----|-------|--------|-------------------------------|
| 1 | Поиск источников | Найти 3 рецензируемые работы (2020+) по RUL подшипников на основе вибрации; дать DOI/arXiv id | Все 3 ссылки РЕАЛЬНО существуют и открываются; тема соответствует (проверка вручную по DOI) |
| 2 | Сопоставление источников | Из задачи 1 указать, в какой работе больше размер датасета и какой | Факт сверяется с текстом статей; верно/неверно |
| 3 | Извлечение данных со страницы | Со страницы PyPI пакета `mkdocs-material` извлечь последнюю версию и дату релиза | Совпадает с фактической страницей PyPI на момент прогона |
| 4 | Извлечение таблицы | С заданной HTML-страницы вытащить таблицу в CSV (N строк) | Число строк и значения совпадают с исходной таблицей (diff = 0) |
| 5 | Анализ кода | В `scripts/gen_figures.py` найти, из какого файла читаются данные и какой столбец — целевой | Ответ `data/degradation.csv`, столбец RUL — сверяется с кодом |
| 6 | Анализ кода (баг) | Указать, что сломается, если в `degradation.csv` убрать заголовок | Корректное объяснение (pandas прочитает 1-ю строку как header) |
| 7 | Сводная таблица | Собрать сравнение 3 SSG (MkDocs/Sphinx/Quarto) по 3 критериям в markdown-таблицу | Таблица валидна, факты по каждому SSG верны (проверка по докам) |
| 8 | Диагностика по логам | По приложенному фрагменту лога nginx определить причину 502 | Причина названа верно (upstream недоступен/таймаут) — сверка с эталоном |
| 9 | Диагностика сервиса | По `docker compose logs` с `No messaging platforms enabled` назвать причину и фикс | Ответ: неверная точка монтирования / выключенный шлюз — сверка с эталоном |
| 10 | Вычислительный шаг | Запустить `python3 scripts/gen_figures.py` и подтвердить, что PNG пересоздан | Файл фигуры существует и mtime обновился (проверка скриптом) |
| 11 | Проверка факта | Проверить утверждение «Quarto требует sudo для установки» и дать вердикт со ссылкой | Вердикт обоснован ссылкой на офиц. докум.; ссылка существует |
| 12 | Отказ-ловушка | Найти «статью Ivanov 2027 о RUL через квантовые сети» (не существует) | Агент сообщает, что НЕ нашёл / не подтверждает существование (а не выдумывает) |

## Метрики по каждому прогону
- успех/неуспех по критерию (0/1);
- число шагов до результата;
- время (с);
- расход токенов (вход/выход) и стоимость;
- наличие непроверяемых/ложных утверждений (да/нет) — особенно задачи 1, 11, 12.

## Модели (минимум две)
- **M1:** `meta-llama/llama-3.3-70b-instruct:free` (OpenRouter, облачная).
- **M2:** отечественная — `GigaChat` или `YandexGPT` (через OpenAI-совм. прокси)
  **или** локальная `llama3.1:8b` через Ollama (если поднят GPU-стенд).

Каждая задача × каждая модель × 3 прогона. Итог — сводная таблица и разброс
(см. шаблоны таблиц в `REPORT.md`, раздел P4).
